предстоит и что нужно от команды. Этап и план по сторонам — `ROADMAP.md`;

## 3. Есть в коде, но выключено

- **Реранкер** (BH-32, `RAG_RERANK_MODEL`) — решение 04.10 (Р-14):
  включать после починки длинных «разговорных» вопросов. Починка (BH-40)
  встроена 04.10: вопросы длиннее 24 слов идут без реранкера. Осталось
  включить на стенде — ручной шаг на сервере (`STAGE.md` §5).
- **«База знаний 2.0» Битрикс24** — скрыта до живой проверки (Р-11).
- **Открытая регистрация на боевом домене** — выключена
  (`REGISTRATION_ENABLED=false`) до юридических текстов.
- **Приём записей на созвон** на стенде — выключен (`LEADS_ENABLED`).
- **Оплата через Точку** (`PAYMENTS_PROVIDER=tochka`, 09.10): подписка
  счётом или картой, пакеты картой, зачисление по вебхуку банка, акты,
  вкладка «Оплата» в панели. Решение 10.10: пока клиентов нет — оплата
  по счёту вручную (счёт из интернет-банка, отметка в панели); ключ API
  — когда клиентов станет несколько, эквайринг — когда компании начнут
  подключаться сами (`DECISIONS.md` 10.10).
- **Гибридный поиск, M2, multi-query** — замерены ML, не включаем
  (`ml-summary.md`).
