## Как работает код — короткая карта

Подробно с потоками — `ARCHITECTURE.md`, раздел 5. Здесь — где что искать.

- **Вопрос сотрудника** — `services/faq_service.py::answer`. Порядок:
  пул кредитов → режим компании → словарь (только в поиск) → эмбеддинг →
  поиск (`vector` или `hybrid`, `_retrieve`) → бюджет контекста → модель
  → пометка/отказ → строка `qa_log` и пороги кредитов одной транзакцией.
- **Документ** — `services/material_service.py::upload` (проверки в
  процессе API, разбор в дочернем `ingest/sandbox.py`), очередь
  `ingest_jobs`, воркер `worker.py` → `services/ingest_service.py`.
- **Изоляция** — `core/database.py` (хуки), `core/tenant_context.py`,
  `core/db_policies.py` (RLS и триггер аудита; один источник для
  миграций и тестовой схемы).
- **Вход и сессии** — `services/auth_service.py`, `core/security.py`,
  `api/v1/dependencies.py::get_current_user_allow_password_change`.
- **Ночные задачи** — `cli.py`: `purge` (`services/retention_service.py`),
  `gaps` (`services/gap_report_service.py`).
- **Настройки** — `core/config.py`: `Settings`, `LLMSettings`,
  `RagSettings` (без дефолтов — значения ML), `GapsSettings`,
  `BillingSettings`, `HttpSettings`.
- **Где ловится ошибка** — `core/exception_handlers.py` +
  `core/middleware.py::RequestIDMiddleware` (необработанное → JSON 500).
- **Коннекторы** — настройка: `services/connector_service.py` и
  `api/v1/endpoints/connectors.py` (в том числе OAuth: `oauth_start`,
  `oauth_callback`); синхронизация:
  `services/connector_sync_service.py` (в воркере, `worker.py::SyncWorker`
  + планировщик раз в минуту); адаптеры и каталог: `connectors/`
  (`registry.py` — виды, `default_registry(settings)`; `bitrix24/` —
  `client.py`, `oauth.py`, `disk.py`, `knowledge_base.py`,
  `adapter.py`); проверка против источника без базы:
  `services/connector_check_service.py` + `cli connector-check`;
  секреты: `core/secrets.py`; state OAuth: `core/security.py`; защита
  от SSRF: `core/outbound.py`; права на документ: `materials.visibility`
  + `material_access`, фильтр `_visible_to` в
  `repositories/chunk_repository.py`.

## Дальнейшие действия — MVP по досье

Что осталось до MVP (3.3): **коннекторы** (10.5). Дизайн — `DECISIONS.md`,
запись «Коннекторы к источникам документов». Форматы «по спросу»
(`.doc`, `pptx`) — предложение, не утверждено; персональные лимиты —
этап расширения.

Правило этапа: тесты → зелёный CI → живая проверка на стенде → запись
здесь. Без живой проверки этап не закрыт.
