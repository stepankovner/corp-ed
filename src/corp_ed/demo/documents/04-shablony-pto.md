# Реестр шаблонов ПТО

Документ вымышленный: создан для демонстрации kronto. Страница вики производственно-технического отдела.

## Исполнительная документация

ПТО-05 — Журнал входного контроля материалов. Файл: ПТО-05_Журнал_входного_контроля.xlsx.

ПТО-06 — Общий журнал работ.

ПТО-07 — Акт освидетельствования скрытых работ (АОСР). Файл: ПТО-07_Акт_скрытых_работ.docx.

Подписанты: представители застройщика, генерального подрядчика и лица, осуществляющего авторский надзор. К акту прилагается исполнительная схема.

ПТО-08 — Акт освидетельствования ответственных конструкций.

## Проектная документация

ПТО-11 — Шаблон пояснительной записки. Оформляется по ГОСТ Р 21.101, титульный лист — по форме компании.

ПТО-12 — Лист регистрации изменений в рабочей документации. Изменения утверждает главный инженер проекта.

## Где лежат файлы

Актуальные версии шаблонов — в папке «ПТО / Шаблоны» на общем диске. Типовые узлы и альбомы — в папке «ПТО / Типовые решения». Устаревшие версии переносятся в архив и для новых объектов не используются.
