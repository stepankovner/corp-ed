# Инструкция по охране труда на объекте

Документ вымышленный: создан для демонстрации kronto.

## Раздел 1. Допуск на объект

1.1. На строительный объект допускаются работники, прошедшие вводный инструктаж и первичный инструктаж на рабочем месте.

1.2. Посетители проходят на объект только в сопровождении ответственного работника и после целевого инструктажа.

## Раздел 2. Средства индивидуальной защиты

2.1. На территории объекта обязательны защитная каска, сигнальный жилет и защитная обувь.

2.2. При работах на высоте более 1,8 метра используется страховочная система с удерживающей привязью.

2.3. Средства индивидуальной защиты выдаёт кладовщик объекта под подпись в личной карточке учёта.

## Раздел 4. Действия при несчастном случае

4.1. Пострадавшему оказывается первая помощь, при необходимости вызывается скорая помощь по номеру 112.

4.2. О случившемся немедленно сообщается руководителю работ и инженеру по охране труда.
