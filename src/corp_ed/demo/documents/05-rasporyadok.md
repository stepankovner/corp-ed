# Правила внутреннего трудового распорядка

Документ вымышленный: создан для демонстрации kronto.

## Раздел 3. Режим работы

3.1. Для работников офиса установлена пятидневная рабочая неделя продолжительностью 40 часов с выходными днями в субботу и воскресенье.

3.2. Начало рабочего дня — 9:00, окончание — 18:00, перерыв на обед — с 13:00 до 14:00.

3.3. Для работников на объектах режим работы устанавливается графиком объекта, который утверждает руководитель проекта.

## Раздел 4. Отпуска

4.1. Ежегодный оплачиваемый отпуск — 28 календарных дней.

4.2. График отпусков утверждается до 15 декабря на следующий год.

4.3. Перенос отпуска на другие даты оформляется заявлением в СЭД не позднее чем за 14 календарных дней до начала отпуска по графику и согласуется с руководителем подразделения.

## Раздел 5. Испытательный срок

5.1. Испытательный срок для новых работников — 3 месяца.

5.2. За две недели до окончания испытательного срока руководитель проводит оценку: встреча с работником и заполнение листа оценки в СЭД.
