# Инструкция по пожарной безопасности

Шифр документа: SV-GEN-009
Редакция: 5.0 от 12.03.2026
Владелец: административный отдел

1. При обнаружении возгорания нажмите кнопку пожарной сигнализации и позвоните по номеру 112.
2. Сообщите на проходную по внутреннему номеру 1000.
3. Покиньте здание по плану эвакуации, лифтами не пользуйтесь.
4. Сбор — на парковке у ворот, ответственный за пересчёт — руководитель отдела.
5. Огнетушители находятся на каждом этаже у лестницы; проверка — раз в полгода.

Учебная эвакуация проводится дважды в год: в мае и в ноябре.
