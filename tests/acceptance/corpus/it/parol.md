# Политика паролей

Шифр документа: SV-IT-003
Редакция: 3.0 от 05.05.2026
Владелец: ИТ

- Минимальная длина пароля — 12 символов.
- Пароль должен содержать буквы разного регистра, цифры и спецсимвол.
- Смена пароля — раз в 90 дней.
- Повторное использование последних пяти паролей запрещено.
- Для администраторов систем обязателен второй фактор.

Правила действуют для всех учётных записей компании, включая служебные.
