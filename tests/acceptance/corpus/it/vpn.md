# Инструкция по настройке VPN

Шифр документа: SV-IT-002
Редакция: 1.8 от 27.04.2026
Владелец: ИТ

1. Установите клиент VPN с внутреннего портала ИТ.
2. Адрес шлюза: vpn.severny-veter.test (вымышленный адрес для примера).
3. Войдите под своей учётной записью, второй фактор — код из приложения-аутентификатора.
4. Проверьте доступ: откройте внутренний портал, он должен загрузиться.
5. Если соединение рвётся, смените протокол в настройках клиента на TCP.

Работа в публичных сетях без VPN со служебными системами запрещена.
